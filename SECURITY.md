# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 1.x | ✅ Активно |

## Сообщение об уязвимости

**НЕ создавай публичный Issue для уязвимости!**

Вместо этого напиши автору напрямую через GitHub: https://github.com/lunarshe11

Укажи:
- Тип уязвимости
- Шаги воспроизведения
- Возможное влияние
- Модель роутера и версия KeeneticOS

## Известные риски

⚠️ **Проект написан ИИ и не проходил аудит безопасности.**

Не рекомендуется использовать на продакшн-роутерах без предварительного:
- Просмотра всего кода
- Изменения стандартного пароля
- Настройки HTTPS
- Ограничения доступа по IP

## Базовые рекомендации

1. **Смени стандартный пароль** `admin:keenui` сразу после установки
2. Не открывай порт 80 в интернет
3. Используй VPN для удалённого доступа
4. Регулярно проверяй `/opt/var/log/lighttpd/access.log`
5. Обновляйся после релизов
