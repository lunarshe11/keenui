# Code of Conduct

## Наши принципы

Участники проекта обязуются:

- Общаться вежливо и уважительно
- Принимать конструктивную критику
- Фокусироваться на проблеме, а не на личности
- Помогать новичкам

## Недопустимо

- Оскорбления, троллинг, личные нападки
- Дискриминация по любому признаку
- Публикация чужих персональных данных
- Спам и оффтоп

## Область применения

Правила действуют в:
- Issues
- Pull requests
- Discussions
- Связанных чатах и комментариях

## Нарушения

Меры: предупреждение → временный бан → постоянный бан.
