# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-09-13

### Добавлено
- 9 вкладок: Дашборд, Система, Keen, WiFi, Сеть, Клиенты, Компоненты, Файлы, Инструменты
- Авто-обновление Дашборда и darkstat каждые 10 секунд
- Basic Auth защита через lighttpd
- Принудительная смена пароля при первом входе
- vnstat: графики трафика (сводка, часы, дни, месяцы, топ)
- darkstat: мониторинг хостов в реальном времени
- cron: просмотр, добавление, удаление задач
- WiFi: управление 5GHz и 2.4GHz точками доступа
- DNS: добавление и удаление серверов
- DHCP: просмотр пулов
- NextDNS: управление профилями и привязками
- Клиенты: Static IP, WOL, блокировка, переименование
- Компоненты KeeneticOS: установка и удаление
- Файлы: USB-устройства и проводник с CRUD
- RCI-консоль для выполнения команд
- Просмотр логов lighttpd
- PWA-манифест и service worker
- Favicon и логотип

### Технические детали
- Backend: lighttpd + CGI (shell + Python3)
- Frontend: vanilla JS без фреймворков
- ~1300 строк JS, ~200 строк CSS, ~280 строк HTML
- Дизайн: тёмная тема, адаптив, CSS-переменные
